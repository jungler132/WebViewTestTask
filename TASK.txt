ТЗ: Мобильное приложение «Hub & Tools» (Тестовое задание для React Native Developer)
Цель: Разработать мобильное приложение на React Native (iOS и Android), демонстрирующее навыки работы с нативной интеграцией WebView (включая обработку глубоких ссылок и внешних приложений), создания UI/UX, работы с анимациями, локальным стейтом.
Part 1. Экран Webview-интеграции (Основная задача)
На главном экране должен располагаться блок «INTERACTIVE WEBVIEW DEEP LINKS» с 4-мя брендированными кнопками. При нажатии на каждую из них должен открываться WebView с соответствующим сервисом.
Бренды:
1win 
Mostbet 
Pin-Up
Aviator 
⚙️ Технические требования к WebView:
Поддержка Deep Linking & Intent: Роутинг должен корректно обрабатывать редиректы. Если внешняя ссылка ведет на приложение банка (Сбер, СБП, Tinkoff и др.), электронный кошелек или другие сторонние сервисы, WebView должен уметь открывать 
Платежные шлюзы и 3D-Secure: WebView должен беспрепятственно обрабатывать транзакции, редиректы на страницы оплаты, а также корректно открывать модальные окна (включая загрузку файлов/камеры, если это требуется для верификации/регистрации).
Индикация загрузки: Наличие стильного Skeleton-экрана или кастомного лоадера (Progress Bar) вверху экрана во время загрузки страниц WebView.
Навигация: Возможность вернуться на предыдущую страницу внутри WebView 
Обработка ошибок: Стейт для обработки отсутствия интернета или ошибок загрузки страницы с возможностью перезагрузить экран (Кнопка "Повторить").






Part 2. Экран «Локальный интерфейс» 
Ниже под кнопками WebView находится раздел «LOCAL INTERFACE» для проверки ваших frontend-компетенций:
Модуль "Balance Tracker" (Финансовый трекер):
Карточка с градиентным фоном и балансом пользователя (например, $1,240.50 с анимацией подсчета цифр при загрузке — Animated Counter).
График доходов/активности (можно использовать react-native-svg или готовые библиотеки, например react-native-chart-kit).
Интерактивные кнопки "Top Up" (Пополнение) и "Send" (Отправить), которые открывают кастомные модальные окна с валидацией ввода.
Модуль "Task Checklist & Analytics":
Список задач/активностей с возможностью отмечать выполнение (чекбоксы с микро-анимациями).
Динамический прогресс-бар, который заполняется в зависимости от количества выполненных задач.
Статус-бары, отображающие API Status ("OK") и App Performance ("99.4%"), которые должны асинхронно обновляться/имитировать загрузку данных при запуске.
🎨 Требования к верстке и UI/UX (см. референс):
Стиль: Темная, неоновая, высокотехнологичная тема (Deep Blue / Dark Purple) с мягким свечением (glow) и градиентами.
Кастомные кнопки: Кнопки WebView должны иметь уникальный дизайн, соответствующий стилю каждого бренда, с использованием иконок, теней, градиентов и эффекта нажатия (Scale/Opacity).
Адаптивность: Корректное отображение на экранах с "челкой" (SafeAreaView) как на iOS, так и на Android. Размеры элементов должны быть относительными (избегать жесткого хардкода пикселей).
Сглаженные углы (border-radius), размытие (blur) и качественные переходы.
🛠️ Стек & Архитектура:
React Native: 
Навигация: React Navigation (Stack + Tabs).
WebView: react-native-webview.
Управление состоянием: Redux Toolkit, MobX или Context API (для управления состоянием локальных задач).
Анимации: react-native-reanimated или встроенный Animated.
