# App Start Instructions

Как запустить **Hub & Tools** локально. WebView и intent проверять **на телефоне или эмуляторе**, не в браузере (`npm run web` для этого задания не подходит).

Проект на **Expo SDK 58**.

## Что нужно

- Node.js 18+
- [Expo Go](https://expo.dev/go) на телефоне, **той же мажорной версии SDK 58** (обновить из App Store / Google Play)
- Телефон и компьютер в одной Wi‑Fi, без VPN

## Команды

В корне репозитория:

```bash
npm install
npx expo start
```

Если PowerShell пишет, что выполнение сценариев запрещено, вызывайте через `.cmd`:

```powershell
npm.cmd install
npx.cmd expo start
```

Дальше в терминале Metro:

- `a` — Android-эмулятор
- `i` — iOS-симулятор (только macOS)
- QR — открыть на физическом устройстве

## iPhone / Android: как открыть QR

1. Запустите **Expo Go** (не системную Камеру).
2. В Expo Go нажмите **Scan QR code** и отсканируйте QR из терминала.
3. Камерой iPhone сканировать нельзя: Safari будет бесконечно открывать проект и выкидывать на рабочий стол.

После правок в коде в Expo Go: потрясти устройство → **Reload**. Либо перезапустить Metro с очисткой кэша:

```bash
npx expo start --clear
```

## Если проект не грузится или сразу закрывается

Частая причина на Windows + iPhone — файрвол / гостевая Wi‑Fi, порт 8081 недоступен с телефона. Тогда туннель:

```bash
npx expo start --tunnel --clear
```

Первый запуск туннеля может минуту ставить `@expo/ngrok`.

Порт **8081** занят старым Metro:

```powershell
netstat -ano | findstr :8081
taskkill /PID <PID_из_последней_колонки> /F
npx expo start
```

Либо согласиться на порт 8082, когда Expo спросит.

Если приложение открылось и сразу вылетело на рабочий стол — обновите Expo Go под SDK 58 и снова `--clear`.

## Разрешения

Камера и фототека прописаны в `app.json`. Система спросит их при загрузке файла / верификации внутри WebView.

Описание архитектуры, редиректов WebView и тестов по ТЗ — в [README.md](README.md).
